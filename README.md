🚗 Integration Engineer Practice Lab

This project simulates an embedded system environment for an integration engineer. It focuses on developing and integrating the following components and skills:
🧠 Key Focus Areas

    Sensor data collection (temperature, light, motion, etc.)

    CAN Bus simulation and analysis

    Embedded system modeling using Scilab + Xcos

    GUI development with Flutter

    Communication interfaces (Wi-Fi, serial, BLE)

    Hardware control (LEDs, fan/motor via relay/MOSFET)

    Testing and integration workflow with SavvyCAN, Git, and ESP-IDF

⚙️ Tools & Technologies

    ESP32

    Scilab + Xcos

    SavvyCAN

    Flutter SDK

    Git / GitHub

    BME280, BH1750, PIR, WS2812 LEDs, DC motor

    MCP2515 (CAN Module)

🎯 Goal

To build a showcase-ready learning project that prepares you for real-world integration engineer roles—no company training required.
